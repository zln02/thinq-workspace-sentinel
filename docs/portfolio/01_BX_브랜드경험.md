## 1. 브랜드 포지셔닝 & 네이밍

### 1.1 네임: Space Sentinel
- **Sentinel(파수꾼/보초병)** — "공간을 지키는 보초". 사람이 24시간 감시할 수 없는 병동을 **공간 스스로가 감시·대응·기록**한다는 핵심 컨셉을 한 단어로 압축.
- **Space(공간)** — 감염 위험의 무대인 "병실/병동이라는 공간"을 주체로 끌어올림. 제품명 진화는 `Workspace Sentinel → Space Sentinel → ThinQ Space Sentinel`(LG 생태계 정렬)로 정리되었다.
- **풀 로크업:** `ThinQ Space Sentinel` (부스/영상 클로징 로고 카드).

### 1.2 한 줄 포지셔닝 (브랜드 정의)
> **"지역 감염이 병원에 닿기 몇 주 전, 외부 신호를 읽고 공간이 스스로 먼저 방역을 준비하는 요양병원 감염관리 시스템."**
> — [홍보영상 전략 v2 §1](../발표/홍보영상_전략_AI광고_v2.md)

차별화의 핵심은 "**경보가 아니라 액션**"이다. 일반 공기질 IoT가 "지금 나쁨"을 보여줄 때, Sentinel은 외부 역학 신호로 "**센서는 아직 정상이어도 미리 켠다**"는 선제 대응을 한다.

### 1.3 슬로건 / 태그라인 (실제 사용 카피)
| 용도 | 카피 |
|---|---|
| 메인 태그라인(영상 클로징) | **"증상이 나타나기 전에, 공간이 먼저 깨어납니다."** |
| 축약 태그라인 | **"공간이 스스로 대비합니다."** |
| 컨셉 한 줄(덱) | **"보이지 않는 감염 위험을, 보이게 — 그리고 스스로 대응하게."** |
| 핵심경험 컨셉 | **감시·대응·기록 — 세 가지를 모두 "사람에서 공간으로"** |

### 1.4 브랜드 메시지 3축 (절대 흔들지 않는 축)
1. **선제성** — 외부 신호로 위험이 닿기 전에 감지 (약국 감기약 판매가 인플루엔자 확진 피크보다 평균 6~7주 선행, WHO FluNet × 실판매 Granger 검정 통과: 순방향 p=0.011)
2. **자동 대응** — 위험도 계산 → 가전 **비례 제어**(항상 최대 아님), 사람 개입 없이
3. **신뢰** — 모든 대응 자동 기록 = 감염관리 증빙(적정성평가), 한계를 먼저 공개

> **규칙:** 새 색 추가 금지. CTA·강조는 항상 coral, 긍정/제목은 ink-green, 위험만 alert. 장식색이 브랜드색보다 튀면 안 됨.

### 2.2 컬러 시스템 ② — 5단계 위험(Risk Tier) 컬러
제품의 시그니처 비주얼 언어. 감염 위험도를 **MONITOR → CAUTION → ALERT → HIGH_RISK → CRITICAL** 5단계로 표현하며, 청록→주황→빨강의 그라데이션이 "안전→위험"을 직관화한다. 백엔드 `_TIER_NAMES`와 홍보영상 테마 토큰이 동일 체계를 공유한다([backend/api/sensor.py](../../backend/api/sensor.py) L144-145, [ad-video/src/theme.ts](../../ad-video/src/theme.ts)):

| Tier | 의미 | 영상 토큰(HEX) | 자동 제어 |
|---|---|---|---|
| MONITOR | 평상 (대기·에너지 절약) | teal `#2DD4BF` / green `#34D399` | idle |
| CAUTION | 주의 (선제 약대응) | amber `#F4B860` | 공기청정 LOW |
| ALERT | 경보 | orange `#FB923C` | 강 자동제어(급속+송풍) |
| HIGH_RISK | 고위험 | orange-red | 강 자동제어 |
| CRITICAL | 위급 | red `#F2545B` | 관리자 승인 후 제어 |

> 이 컬러바는 **하이브리드 거버넌스**(ALERT까지 자동 / CRITICAL은 사람 승인)를 색으로 설명하는 장치이기도 하다.

### 2.3 타이포그래피
- **발표덱:** **Pretendard 단독** (SVG 차트의 `font-family`까지 Pretendard). 역할별 스케일 고정 — 제목(H2) `44px/800`, 부제 `21px/500`, 챕터 라벨 `30px/800`, 페이지번호 `17px/600`, 히어로 숫자 `33~58px/900`. 본문은 `19px` 아래로 내려가지 않음.
- **홍보영상:** `NanumSquare` / `NanumSquareRound` (둥근 톤으로 따뜻함 보강).

### 2.4 아이콘·모션 언어
- 외부 5층 신호 아이콘 세트(질병청·하수·검색·약국·기온)를 한 줄 흐름으로 슬라이드인.
- 로고 마크 `● Sentinel` (점 = coral 포인트), 화살표 흐름 `→`(`#C8A88C`), 애니 클래스 `.bx-rise`(등장)·`.hl`(코랄 형광펜)·`.count-up`(숫자 카운트업).
