## 3. 레이아웃 — 슬라이드 골격(모든 슬라이드 동일)

```html
<section style="display:flex; flex-direction:column; background:#F4EEE3;
                padding:52px 76px 48px; position:relative;
                font-family:'Pretendard Variable',Pretendard,sans-serif;">
  <!-- ① 헤더 (아래 컴포넌트) -->
  <!-- ② 제목 H2 (결론 문장) -->
  <!-- ③ 부제 1줄 -->
  <!-- ④ 본문: flex:1; min-height:0  (남는 공간 꽉 채우기) -->
  <!-- ⑤ 결론 바 .concl -->
  <!-- ⑥ 페이지수(하단중앙) + 푸터(우하단) -->
</section>
```
- 외곽 패딩 ≈ `52px 76px 48px`
- 본문 영역은 `flex:1; min-height:0` → **빈 공간 남기지 말 것**(위 쏠림 금지, `justify-content:space-between`/`center`로 채움)

## 4. 핵심 컴포넌트 (복붙용)

### ① 헤더 — `단계 ── 주제`
```html
<div style="display:flex; align-items:center; gap:22px; margin-bottom:18px;">
  <span style="font-size:30px; font-weight:800; color:#2F4135; white-space:nowrap;">BX<span style="color:#B05F3B;">.</span>추진배경</span>
  <span style="flex:1; height:2px; background:#2A2620; opacity:0.85;"></span>
  <span style="font-size:29px; font-weight:800; color:#2A2620; white-space:nowrap;">SWOT 분석</span>
</div>
```
- 좌측 단계: `BX.추진배경` / `CX.핵심 경험` / `DX.설계`(DX는 좌측색 `#7a0024` 허용)
- 점(`.`)은 coral. 우측은 그 슬라이드의 주제.

### ② 결론 바 `.concl` (모든 분석 슬라이드 하단)
```html
<div class="concl"><span class="tag">결론</span><span class="txt">한 문장 결론(다음 장으로 다리)</span></div>
```
```css
.concl { background:#DCE7C5; border:1px solid rgba(47,65,53,0.2); border-radius:12px; padding:12px 22px; display:flex; align-items:center; gap:14px; margin-top:12px; }
.concl .tag { font-size:17px; font-weight:800; color:#fff; background:#3A4F42; border-radius:6px; padding:5px 13px; }
.concl .txt { font-size:22px; font-weight:600; color:#28332B; line-height:1.32; }
```

### ③ 페이지수 + 푸터
```html
<div class="pageno" style="position:absolute; bottom:24px; left:50%; transform:translateX(-50%); font-size:17px; font-weight:600; color:#B0A695; letter-spacing:0.06em;">N / 23</div>
<div style="position:absolute; bottom:22px; right:44px; font-size:20px; font-weight:600; color:#C7BCA9; letter-spacing:0.04em;">LG DX School</div>
```

### ④ 카드 (기본 / 스포트라이트)
- 기본: `background:#ECE4D6; border:1px solid rgba(47,65,53,0.1); border-radius:16px; padding:20px 24px;`
- 스포트라이트(핵심 1개만): `background:linear-gradient(150deg,#3A4F42,#2F4135); color:#fff; box-shadow:0 12px 30px rgba(47,65,53,0.28);` + 골드 뱃지
- **나머지 카드는 `opacity:0.55~0.62`로 흐리게** → 핵심만 도드라지게

### ⑤ 흐름/단계 연결
`→` 화살표: `font-size:26~32px; color:#C8A88C; font-weight:900;` (단계 사이)

## 5. 애니메이션 클래스 (이미 정의됨)
- `.bx-rise` 떠오르기(등장) — `animation-delay`로 순차
- `.blink` 깜빡(강조/위험) · `.pop` 팝(숫자) · `.hl` 코랄 형광펜(`<span class="hl">강조</span>`)
- `.bar-grow`/`.bar-grow-y` 막대 · `.count-up`(`data-target`) 숫자 카운트업

> **규칙**: 무한 애니(.blink)는 슬라이드당 1~2곳만. 과하면 성능·산만.

## 6. 절대 규칙 (심사·가독성)
1. 제목·부제·챕터·페이지수 — **같은 위치·같은 크기**
2. **Pretendard만** (SVG 차트 포함)
3. 제목 = **그 슬라이드의 결론 문장**
4. 차트·그래프 **최대한 많이**, 크게(라벨 읽히게)
5. **빈 공간 최소** — 본문 위로 쏠리지 않게 채움
6. **출처 표기** — 데이터/수치엔 출처(외부신호=WHO FluNet·KOWAS·DataLab·OTC·코웨이 / 시장=통계청·KT경제연 등)
7. **16:9만** · 레이아웃 단단하게(오버플로 0)
8. 핵심 1개 히어로 + 나머지 흐림(dim) — "어디 볼지" 명확히
9. 정직성: LG가전=코웨이 1종 실증+SDK(나머지 Mock), r=0.82=외부 WHO truth, MOU 0건 — **과대포장 금지**
