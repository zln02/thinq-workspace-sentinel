## 3. 화면별 설계

### 3.1 통합 로그인 `/`
- **목적:** 병원·계정 선택 후 진입 · **대상:** 전 사용자
- **UI:** 병원 드롭다운, ID/PW, 다크 글래스 카드, 배경 파티클
- **이동:** SUPER → `/select`, 그 외 역할 → `/dashboard`

### 3.2 대시보드 — 간호사 관제 (NURSE) `/dashboard`
- **목적:** 실시간 병동 감염위험 감시·즉시 경보 · **대상:** ICN·수간호사
- **UI 구성:**
  1. 병동 전체 상태 요약 밴드(최악 tier 색/카운트)
  2. 외부 감염병 조기경보 배너(질병청·UIS, boost 토글)
  3. 병동 환경 실시간 관제맵(4색 카드 그리드 → 클릭 상세 모달)
  4. 간호 조치 가이드(위험등급별 권장 행동)
- **데이터:** `useLiveWard`(201호 SSE 1s) · `useSpacesOverview` · `useExternalSignal`

### 3.3 대시보드 — 시설·가전 제어 (FM)
- **목적:** ThinQ 가전 자동방역·HVAC 제어 · **대상:** 시설관리자
- **UI 구성:**
  1. KPI 4(감시 공간·자동대응·코웨이 상태·30일 자동건수)
  2. 실 가전 제어 콘솔(자동/수동 모드 전환[비번], 제어 대상 호실 선택 — **201호 실센서만**)
  3. 가전 필터(실연동만/핵심/보조/위생편의/전체)
  4. 코웨이·에어컨·미연동 가전 카드(근거 뱃지 + 제어 버튼)
  5. 호실별 환경 시계열 · 의사결정 흐름 · 외부경보→가전 차등제어 맵
- **데이터:** `useSpacesOverview`·`useCowayStatus`·`useAcStatus`·`useControlPlan`·`sendControl`·`setControlMode`

### 3.4 대시보드 — 경영 리포트 (DIRECTOR)
- **목적:** ESG·ROI·감염관리 성과·법규 증빙 · **대상:** 원장·경영진
- **UI 구성:**
  1. AI 자동 브리핑(타이핑 효과, 모델 산출값 자연어 요약)
  2. 감염병 사전예방 성과(외부 선행 포착일·선제 자동대응·결과)
  3. 핵심 KPI 4(자동 선제대응·모니터링 기록·방역비 절감·최고 위험)
  4. 수동 vs ThinQ 자동제어 비용 비교 차트
  5. 공간별 감염위험 현황(라이브)
  6. 법규 준수 자동 증빙(의료법·감염병예방법·실내공기질·심평원)
- **데이터:** `useReport(30)` · `useSpacesOverview`

### 3.5 대시보드 — 추이 분석 (ANALYTICS)
- **목적:** PoI·환경 시계열 + 자동방역 의사결정 흐름 검증 · **대상:** 감염관리팀
- **UI 구성:** PoI 추이 차트(Rudnick-Milton, 참조선 5/15/30%) · 온습도·CO₂ 시계열(기준선 습도 40~60%·CO₂ 800) · 의사결정 흐름(외부→센서→계산→등급→거버넌스)
- **데이터:** `useLiveWard`·`useRiskSeries`·`useSensorSeries`

### 3.6 보호자 앱 — 스플래시 `/guardian`
- **목적:** 진입·로그인 · **대상:** 보호자
- **UI:** 풀스크린 일러스트(요양 거실) + 상단 로고(ThinQ SENTINEL) + 하단 "탭하여 로그인"(깜빡임). 탭 → 세션 생성 → `/guardian/home`

### 3.7 보호자 앱 — 홈 `/guardian/home`
- **목적:** 안심 상태 한눈에 · **대상:** 보호자
- **UI:** 연결상태 인디케이터 · **안심 메인 카드**(환자·병동, 큰 상태 라벨+이모지+메시지, 업데이트 시각, tier 색 배경) · "지금 병원이 하는 일"(공기청정/환기/24h케어/습도)
- **데이터:** `useLiveWard`(실시간 tier)

### 3.8 보호자 앱 — 병동 `/guardian/ward`
- **목적:** 공기질 상세 · **대상:** 보호자
- **UI:** 감염 위험도 카드(PoI%) · 실시간 공기질 4종(CO₂/PM2.5/온도/습도, 임계 초과 색) · 실내 공기 등급(코웨이 실측)
- **데이터:** `useLiveWard`·`useCowayStatus`

### 3.9 보호자 앱 — 알림 `/guardian/alerts`
- **목적:** tier 전환 이력 · **UI:** 알림 리스트(이모지+상태+메시지+상대시각) / 빈 상태 안내 · **데이터:** `getAlerts()`(전역 tier 변화 감지 누적)

### 3.10 보호자 앱 — 설정 `/guardian/settings`
- **목적:** 알림·정보·로그아웃 · **UI:** 보호자/환자 정보 · 실시간 안전 알림 토글(Notification 권한) · "의료 진단 아님" 안내 · 로그아웃(확인 모달)

### 3.11 3D 병동 위험맵 `/wardmap`
- **목적:** 공간별 tier 입체 시각화(아이소메트릭) · 백엔드 서빙 HTML

## 4. 앱 디자인 가이드 (예시 화면설계서 양식 반영)

- **모바일 우선:** 보호자앱 max-width 430px, 하단 safe-area 탭바, PWA 설치(홈 화면 추가, `manifest.webmanifest` standalone).
- **안심 우선 정보 위계:** 숫자보다 **상태 라벨("안심/주의")** 을 최상단 — 불안 최소화.
- **권한 분리:** 보호자는 조회만(제어 불가), 시설관리자만 가전 제어, 외부경보는 간호사/원장 뷰.
- **정직성 라벨:** 실센서(201호)=`실센서 LIVE`, 파생 호실=`파생추정`, 시뮬=`시뮬` — 센서 없는 공간을 실센서로 표기하지 않음(B2G 정합).
