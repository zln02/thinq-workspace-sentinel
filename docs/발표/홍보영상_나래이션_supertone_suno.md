# 홍보영상 내레이션 + BGM 제작 시트 (Supertone + Suno)

> 용도: **CES 부스 루프 광고** (60~72초, 무한 루프). Remotion 프로젝트 `ad-video`로 합성.
> VO=Supertone(play.supertone.ai, 한국어), BGM=Suno(suno.com).
> 카피는 `정직성_프레이밍_QA.md` + 2026-06-23 최종 입장 기준. **과대포장=즉사.**
> 정직성 교정 반영: 실증 가전 = **코웨이 공기청정기 1종뿐**(삼성❌), CO₂ = **실제 MH-Z19 실측(201호)**, F1·예측은 **외부 UIS 소유**(우리는 라스트마일), MOU **0건(="진행 중"으로만)**.

## 1. Supertone 내레이션 (장면별 — 이대로 한 컷씩 뽑기)

> 추천 보이스: 차분하고 신뢰감 있는 **한국어 내레이터**(여성 또는 중저음 남성), 속도 0.97~1.0배.

| **S2** | 8~18s | "하지만 지역의 감염 확산은, 병원에 닿기 15일에서 43일 전부터 신호를 보냅니다." |

## 3. Suno BGM 프롬프트

**스타일/무드:** 시네마틱, 미니멀 일렉트로닉, 희망적이지만 절제된 긴장감. 도입은 어둡고 조용 → 중반 빌드업 → 후반 따뜻한 해소(resolve). 보컬 없음(instrumental). 의료/테크 브랜드 광고 톤. 70초 내외, 루프 가능하게 시작·끝 잔잔하게.

**Suno 입력(영문 권장):**
```
Cinematic minimal tech ambient, instrumental, no vocals.
Soft dark intro with subtle pulse, gentle piano motif, building to a hopeful warm resolve with strings and soft synth pads. Medical/healthcare brand commercial mood, calm and trustworthy, restrained tension then relief. Steady slow tempo ~80 bpm. Clean, premium, modern. Loopable: start and end quiet and ambient. Length ~70 seconds.
```
- `[Instrumental]` 태그 사용, 가사 비워두기.
- 2~3개 variation 뽑아서 S1(어둡)~S7(해소) 곡선에 맞는 걸 선택.
- 부스 루프이므로 **끝 4초 = 시작 4초와 음량/질감 비슷**해야 이음새 안 보임.

## 4. 합성 워크플로우 (Remotion `ad-video`)

1. Supertone에서 S1~S7 VO 뽑기 → `ad-video/public/audio/vo/s1.mp3` … `s7.mp3` (또는 한 덩어리 `vo_full.mp3`).
2. Suno에서 BGM 뽑기 → `ad-video/public/audio/bgm.mp3`.
3. Remotion 컴포지션이 자막·모션·대시보드 스샷·병동 렌더를 타임라인에 배치(오디오 없어도 비주얼 먼저 완성 → 오디오는 드롭인).
4. `npm run render` → `out/sentinel-ad.mp4` (1920×1080, 부스 루프용).
5. §2 엔딩 고지 자막 + 가드레일 전수 검수 후 배포.
