# ThinQ Space Sentinel — 3분 시연 대본 (최종 · 2026-06-23)

> **2단계 선제대응 스토리** 반영판. 이전 `시연_대본_3분.md`는 발령 즉시 가전 가동(1단계)이었으나,
> 현재 시스템은 **① 외부 발령 = 판정기준만 선제 상향(가전 대기)** → **② 실제 CO₂ 상승(입김) = 가전 자동 가동** 2단계.

## 무대 구성 — 3분할 키오스크 (탭 3개로 통합됨)
| 모니터 | URL | 내용 |
|---|---|---|
| **모니터1** | `?screen=epidemic&voice=1` | 외부 역학 지도(전국 RED 유행) · **발령 토글** · 녹음 나래이션 재생 |
| **모니터2** | `?screen=control` | 관제 (병동·가전 통합) · **3D 병동 + 가동 이펙트** · 간호사/시설관리자 |
| **모니터3** | `?screen=sensor` | 실시간 센서 + 논문 파이프라인 + YOLO 카메라 |

- 외부 URL 베이스: `http://3.34.222.103:3100/demo?screen=...`
- **나래이션은 녹음본**(Supertone): 발령=Take1, 위험상승=Take2, 복귀=Take3 — 모니터1(`&voice=1`)에서 상태 전이 시 자동 재생.
- 시작 상태: **boost 해제(평소)**. 단, 지도엔 광주가 이미 RED(지역 유행 진행 중)로 표시됨.

- 모니터3: **🛡️ 감염병 사전예방 모드** 배너 — "위험 판정 기준 선제 상향"

## [1:05–1:35] ★2단계 — 실제 위험 확인 → 가전 자동 가동
**P2 행동:** CO₂ 센서에 **입김**(또는 다인실 밀집 재현).
**화면(모니터3):** CO₂ 그래프 급상승 → 재호흡분율 f↑ → **전파 위험확률 PoI↑** → 등급 상승.
**🔊 Take2(자동, 가동 전환 시):** "실내 감염병 위험도가 높아지고 있습니다. 가전을 인플루엔자 사전예방 모드로 자동 전환합니다."
**화면(모니터2):** **3D 병동이 활성화** — 밝아지며 가전별 가동 이펙트(공기청정 **TURBO** · 환기 **MAX** · UV-C 살균 · 에어컨 송풍 · 가습), 스캔 스윕 + 등급색 비네트. 가전 강도 그래프 상승. 코웨이 "● 실연동" 배지.
**P1:** "아무도 버튼을 누르지 않았습니다. 간호사는 환자 곁에 있었고, **공간이 스스로 대응**했습니다. 그리고 **근거 없는 가전은 끕니다** — 로봇청소기·스타일러는 호흡기 감염과 무관해서 자동 제외. 과잉제어가 아니라 **논문 근거 기반 선택**입니다."
> ★ DX 충실성(최대배점). 2단계 = 오작동 방지(외부경보만으로 막 돌리지 않음).

## [1:35–2:00] 알고리즘 투명성
**화면(모니터3):** 파이프라인 클로즈업 — `CO₂ → 재호흡분율 f → 전파 위험확률 PoI → 5-Tier`, 라이브 숫자가 수식에 대입.
**P1:** "흔한 IoT는 'CO₂ 800 넘으면 빨간불' 같은 임의 임계값입니다. 저흰 **상수 하나하나 출처 있는 논문 값**이에요 — 재호흡분율은 Rudnick-Milton 2003, 5단계는 Kim et al. 2025, quanta는 Buonanno 2020. **왜 그 등급인지 수식으로 추적됩니다.**"
> PoI는 '감염자 노출 시' 조건부 전파확률로 상시 계산·표시. 등급은 외부 감염신호 발령 맥락에서 격상.

## 2단계 상태기계 파라미터 (참고)
- 외부 발령 → `tier=max(센서,외부경보)` 상향, **가전은 대기**(control_active=false)
- CO₂ 급상승(baseline 대비 +300ppm·1000ppm↑) → **가전 자동 가동**(control_event=activated → Take2)
- CO₂ 정상(800ppm↓) 5초 지속 → **복귀**(control_event=recovered → Take3)
