## 2. 포트폴리오 제출 권장 형태

세 가지를 함께 내면 가장 강합니다.

1. **GitHub 레포 링크** — 첫 화면 README가 곧 소개서 (이미 전문가급으로 정리됨)
2. **1페이지 개인 요약**(아래 템플릿) — "팀 프로젝트에서 내가 무엇을 했는가"를 1장으로

### 본인 기여 추출법

```bash

git log --author="본인이름또는이메일" --oneline --stat
```

## 3. 역할별 어필 가이드

### 🧭 PM / Tech Lead
- **핵심 기여**: 전체 아키텍처 설계, Wells-Riley PoI 모델·시뮬레이터, ML 파이프라인, 외부신호 융합 설계, 문서 총괄
- **보여줄 것**: [DX 문서](03_DX_기술과배포.md) §1·2·6, `pipeline/simulator/rebreathed.py`, README 아키텍처 다이어그램
- **어필 멘트**: "감염확률을 UI로 흉내 내지 않고 **피어리뷰 물리모델(Wells-Riley)** 로 실제 계산하도록 설계. 외부 역학신호(feedforward)와 실내 센서(feedback)를 하나의 위험도로 융합하는 구조를 주도."
- **수치**: 5단계 위험 분류, 병원체 8종 quanta 파라미터화, 75,633건 시장검증 설계

### ⚙️ Backend
- **핵심 기여**: FastAPI 백엔드, **2단계 제어 상태기계**, 가전 어댑터(Coway/SmartThings), SSE, 보안 하드닝
- **보여줄 것**: `backend/api/sensor.py`(상태기계), `backend/services/*adapter.py`, `backend/api/auth.py`, [DX 문서](03_DX_기술과배포.md) §2·4
- **어필 멘트**: "외부경보 → CO₂ 서지 → 회복까지 **오작동 방지 상태기계**를 구현(베이스라인 재고정·쿨다운). 제어 엔드포인트를 **fail-closed + 상수시간 비교**로 하드닝하고 라우트 결선 테스트까지 작성."
- **수치**: 테스트 74개 통과, async 논블로킹, 실가전 2종 연동

### 🖥️ Frontend
- **핵심 기여**: Next.js 14 관제 대시보드(역할별), 보호자 PWA, 5단계 위험 시각화
- **보여줄 것**: `frontend/app/dashboard`, `frontend/components/guardian/`, `frontend/lib/`(hooks·tier), [CX 문서](02_CX_고객경험.md) §4
- **어필 멘트**: "간호사·시설·병원장·보호자 **역할별 경험**을 한 코드베이스에서 분리 설계. 실시간 SSE/폴백, 5단계 위험 컬러 시스템, 모바일 PWA까지."
- **수치**: 역할 4종 화면, Tailwind 디자인 토큰, 정적 빌드 통과

### 🛠️ DevOps / QA
- **핵심 기여**: Docker Compose(7서비스), CI/CD, DB 마이그레이션, TimescaleDB 설계, 부하테스트
- **보여줄 것**: `infra/docker-compose*.yml`, `.github/workflows/ci.yml`, `migrations/*.sql`, [DX 문서](03_DX_기술과배포.md) §5·7·8·9
- **어필 멘트**: "TimescaleDB 하이퍼테이블·보존정책·멀티테넌트 스키마 설계. CI(ruff·pytest·secret-scan) 구축, **캐시 스탬피드 수정으로 p95 9757ms→1113ms** 개선."
- **수치**: 7서비스 오케스트레이션, CI green, 부하테스트 p95 60ms

### 🎨 Strategy / Design (BX·CX)
- **핵심 기여**: 브랜드 아이덴티티·디자인 시스템, 발표덱, 홍보영상, 시장·고객 검증, 정직성 프레이밍
- **보여줄 것**: [BX 문서](01_BX_브랜드경험.md), [CX 문서](02_CX_고객경험.md), 발표덱, 홍보영상
- **어필 멘트**: "네이밍·5단계 컬러 시스템·발표덱 디자인 토큰을 정립. 75,633건 LDA로 시장 페인을 정량화하고, 임상주장 14개를 팩트체크(허위 0)해 **과대포장 없는 신뢰 포지셔닝**을 설계."
- **수치**: 78,087건 크롤·75,633건 분석, 임상주장 14건 검증, 감염예방관리료 ROI

## 5. 면접 대비 — 약점 솔직 대응

포트폴리오의 신뢰도는 **약점을 어떻게 말하느냐**에서 갈립니다. 이 프로젝트는 정직성을 원칙으로 삼았으니 그대로 가세요.

| 예상 질문 | 권장 답변 방향 |
|---|---|
| "테스트 커버리지는?" | "백엔드 핵심 로직 74개 + 보안 결선 테스트. 프론트 자동테스트는 미비 — 다음 우선순위로 명시(README 로드맵)." |
| "실제 병원에 쓸 수 있나?" | "PoC 수준. 의료기기 규제·실파일럿 데이터가 남은 격차이며 레포에 정직하게 공개. 돌려보고 평가받는 용도로는 바로 가능." |
| "감염을 정말 막나?" | "감염률 X% 감소는 주장하지 않음. 환경 개입은 기전 수준 근거가 있고, 우리는 **근거 기반 환경 + 증빙 생성**으로 포지셔닝." |

> 핵심: **'잘 만든 PoC'임을 인정하되, 경계를 정직하게 아는 것**이 오히려 신뢰 포인트입니다.
