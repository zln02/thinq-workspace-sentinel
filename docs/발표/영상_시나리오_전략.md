## 0. 한 줄 정의 (영상 오프닝 고정 문장)

> **"감염을 진단하는 AI가 아니라, 지역 감염 확산이 병원에 닿기 15~43일 전에 가전을 자동으로 준비시키는 실시간 대응 시스템."**

- 결제자: 병원장/운영이사 · 사용자: 감염관리간호사(ICN)

## 2. 메시지 골격 (3축 — 절대 흔들지 말 것)

1. **선제성** — 외부 5층 신호로 확진 피크 **15~43일 선행** 감지
2. **자동 대응** — Wells-Riley 위험도 → 가전 차등 제어(항상 최대 아님, 위험도 비례)
3. **수가로 직결** — 감염관리 활동의 **자동 증빙** = 적정성평가 등급 = 수가(연 5~8억/200병상)

## 6. Opus 제작 워크플로우 (brand-templates-ux 기준)

1. **브랜드 템플릿 설정** (clip.opus.pro/brand-templates-ux)
   - 로고 업로드 / 메인 컬러: 5-Tier 팔레트(MONITOR 청록 → CRITICAL 레드) + 발표 덱 톤 맞춤
   - 폰트·캡션 스타일 지정(키네틱 자막용)
2. **홍보영상**: §4 내레이션을 스크립트로 입력 → AI 보이스(한국어) 선택 → 브랜드 모션 자동 생성 → 키워드 자막 강조 → MP4 export
3. **시연영상**: 화면 녹화본 업로드 → Opus 자동 클립/하이라이트 → §5 자막 오버레이 → 브랜드 캡션 → export
4. **검수**: §3 가드레일 체크표로 카피 전수 확인 후 배포
