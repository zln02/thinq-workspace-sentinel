## 0. 한눈 요약 (정직 라인)
- **진짜 실측**: 재실 인원(노트북 카메라), 외부 역학(UIS 실DB), 알고리즘(논문 수식 실연산), 공기청정기 **상태조회**(코웨이 실기기).
- **임시 대체**: CO2·온습도 = 에뮬레이터(아두이노 펌웨어 복구 전까지). 복구 시 실센서 즉시 전환.
- **시뮬/계획**: 공기청정기 외 가전(환기·가습·에어컨 등) = 제어계획 표시(실연동 1종은 코웨이뿐, 현재 안정화 위해 실작동 OFF).
- **남의 것**: 예측 F1 0.907 = 외부 UIS 소유(우리는 라스트마일). 환자 활력징후 = 미수집(비의료).
- **시스템은 감염을 "막는다"가 아니라 "위험을 낮추고 선제 준비한다".**

## 1. 외부 감염병 조기경보 (UIS)
- **① 시각화**: 모니터3 — 광주 RED 지도, 질환(인플루엔자)·확진피크 21일 전 리드·복합신호(하수/검색/OTC). 발령 토글.
- **② 실제작동(설명 멘트)**: "예측은 외부 UIS(질병청 하수·검색·약국OTC)가 합니다 — F1 0.907은 그쪽 자산이고, **저흰 그 신호를 병동 공기로 번역하는 라스트마일**입니다." → UIS DB 실데이터 라이브 조회(실제 작동).
- **③ 감염저감 근거**: 조기경보로 **증상 전 선제 대응** 가능 = 노출 누적 전 환기·정화 강화. 단 **"검색이 임상을 선행"은 단정 금지**(자체검정서 검색=동시~후행, 선행성 미증명). "공식 감시 기반 복합 조기신호"로만.

## 2. 실내 센서 — CO2·온습도
- **① 시각화**: 모니터1 — CO2/온습도 실시간 그래프 + 매초 갱신 숫자.
- **② 실제작동(설명)**: 현재 **에뮬레이터**(아두이노 펌웨어 행 → 노트북 재플래시 중). 정직 멘트: "공기질 센서는 지금 시연용 피드입니다 — 하드웨어 복구되면 실측으로 바로 전환됩니다." (복구 시 bridge.py 전환, device_id=rpi-arduino 동일)
- **③ 감염저감 근거**: CO2 = **재호흡 공기 비율의 대리지표**(환기 부족 = 에어로졸 축적). CO2 자체가 감염을 옮기는 건 아니나 위험의 정량 신호. Rudnick-Milton 2003.

## 3. 실내 센서 — 재실 인원 (카메라) ✅실측
- **① 시각화**: 공간 카드 occupancy 표시(정원 클램프 적용 — 1인실에 10명 같은 오류 없음).
- **② 실제작동(설명)**: **노트북 카메라가 실제로 사람 수를 셉니다**(laptop-cam, 실측). PoI 계산의 분모(재실 n)에 직접 들어감.
- **③ 감염저감 근거**: 밀집도↑ = 감염확률↑(Wells-Riley n). 재실 기반으로 "사람 많을 때만 강하게" 비례 대응 → 과잉가동 방지.

## 4. 알고리즘 — 재호흡분율 → PoI → 5-Tier ✅실연산
- **① 시각화**: 모니터1 파이프라인 — `CO2 → f=(C−Cₐ)/C₀ → PoI=1−exp(−f·(I/n)·q·t) → 5-Tier`, 라이브 수치가 수식에 대입, 논문 라벨(Rudnick-Milton 2003 / Wells-Riley / Kim 2025).
- **② 실제작동(설명)**: 임의 임계값이 아니라 **상수 하나하나 출처 있는 논문 값**. 코드 함수가 수식 그대로(검증: Kim et al. 2025 Appl.Sci 15:9145 실재 확인). 심사위원 입김 → CO2↑ → f↑ → PoI↑ → tier 점프 실시간.
- **③ 감염저감 근거**: 위험을 **정량·등급화**해야 "언제 무엇을 얼마나" 결정 가능. 알고리즘 자체가 저감하는 게 아니라, **근거 있는 비례 대응의 두뇌**. 정직: 단위테스트는 물리 불변식 검증이지 임상 검증 아님.

## 5. 핵심 차별점 — 선제 격상 (tier = max(센서, 외부경보)) ✅작동
- **① 시각화**: 평소 CAUTION(센서) → 발령 시 **ALERT·source=external**로 점프(검증 완료). co2 정상인데 격상.
- **② 실제작동(설명)**: "센서가 더 민감해지는 게 **아닙니다**. 외부 위험이 높으니 **같은 환경을 더 보수적으로 판정** — 위험 기준선을 선제로 올립니다." (기존 제품은 사후 경보만)
- **③ 감염저감 근거**: 노출 누적 전 선제 강화 = 라스트마일의 핵심 가치. 기존 모니터링 IoT 대비 유일 차별.

## 6. 가전 — 공기청정기 (코웨이) ✅실연동 1종
- **① 시각화**: 모니터2 — "● 실연동(코웨이)" 배지 + 실 풍량(fan/5)·소비전력 애니메이션. 평소 대기 → 경보 TURBO.
- **② 실제작동(설명)**: **유일하게 실제 IoCare 제어되는 기기**(상태조회 라이브). ⚠ 단 현재 **실작동은 OFF**(센서 흔들림에 ON/OFF 난무해서 안정화차 마스터스위치 차단; `.env SENTINEL_ACTUATE=1`로 복원). 시연 시 실가동 보여주려면 이걸 켜고 보드 안정 후.
- **③ 감염저감 근거(보조)**: HEPA 0.3µm 99.97% **포집**(DOE/EPA)·에어로졸 제거 ↔ **포집률을 감염저감률로 표기 금지**. 실내 outcome RCT는 없음(기전 증거만). "보조 수단".

## 7. 가전 — 환기 (환기율/ACH) 🟡계획표시
- **① 시각화**: 모니터2 환기청정기 카드 — 환기율 MED→MAX, "Wells-Riley Q 직접 제어".
- **② 실제작동(설명)**: **제어계획(시뮬)** — 실연동 기기 없음. "어댑터 연동 예정".
- **③ 감염저감 근거(핵심·강함)**: 공기감염 1순위 대책. 결핵 자연환기 28ACH로 위험 39%→11%(Escombe 2007 PLoS Med), ASHRAE 170 격리 12·일반 6 ACH. **근거 가장 강함**.

## 8. 가전 — 가습/제습 🟡계획표시
- **① 시각화**: 모니터2 — 목표습도 50%(인플루엔자).
- **② 실제작동(설명)**: 제어계획(시뮬).
- **③ 감염저감 근거(보조)**: 고습일수록 인플루 비말 안정성↓(Lowen 2007 — 단 **완전차단은 80%RH, 50%는 "감소"**), 고습서 감염력 ~3/4 소실(Noti 2013). 실내 권고 EPA <60%·이상 30~50%(곰팡이). "50%=차단" 금지, "감소".

## 9. 가전 — 에어컨 🟡미연동(시뮬)
- **① 시각화**: 모니터2 — 냉방+환기송풍.
- **② 실제작동(설명)**: SmartThings 토큰 미설정 → **미연동(시뮬)**. 폭염 노인 보호 보조.
- **③ 감염저감 근거(주의)**: 신선외기+필터일 때만 보호적, **재순환은 위험**(Lu 2020 광주 식당 — "환기부족"이 원인, '재순환'은 해석이라 "consistent with"로).

## 10. UV-C (상부 UVGI) ⚪미보유·권장
- **② 실제작동(설명)**: 미보유 → "추가 권장" 항목.
- **③ 감염저감 근거(강함, 단 분리)**: 상부 UVGI 결핵 70%↓(Escombe 2009)·~80%(Mphaphlele 2015) = **공기·결핵**. 표면 UV로봇 MDRO 30%↓(Anderson Lancet 2017, **C.diff 무효**) = **표면·접촉**. ⚠ 두 기술 합치면 과장.

## 11. 로봇청소기·스타일러 ❌감염근거 없음 → 자동 제외
- **① 시각화**: 모니터2 — "근거 없음 → 자동 제외" 박스.
- **② 실제작동(설명)**: 일부러 **끕니다**(과잉제어 방지).
- **③ 감염저감 근거**: 로봇청소기 RCT 0·재부유 역효과(Knibbs 2012 — 일반청소기 연구), 스타일러 60℃ 멸균 미달·독립연구 없음. **솔직히 끄는 게 차별점**(경쟁사는 "살균률"로 과장).

## 12. "진짜 감염위험을 낮추는가?" — 정직한 종합 답
- **개입별 효능**은 동료심사 근거 있음(환기·UVGI 강함 / HEPA·습도 보조 / 로봇·스타일러 없음). **검증 완료** → `docs/발표/임상근거_검증_2026-06-22.md`.
- **단 요양병원 현장 outcome RCT는 부재**. 그래서 정직한 주장 = **"장비가 감염을 N% 줄인다"(❌)** 아니라 **"근거 있는 환경을, 외부위협 시, 선제·비례로 만들고, 증빙을 남긴다"(✅)**.
- 시연에서 **자진 고백 3종**을 클로징 전에 반드시: ①활력징후 미수집(비의료) ②실연동은 코웨이 1종·CO2는 현재 에뮬 ③"막는다" 아님·"위험 낮춤".
